# Name history

msbos had other names before. They appear only in old releases, migration
scripts and this page — the rest of the documentation uses the current name.

| Name | Period | What it was |
|---|---|---|
| **MyOS** | project start | GNOME base; later migrated to Fedora KDE |
| **omyfedora** | first public version | Fedora KDE + niri + Noctalia, installed by scripts |
| **msbos** | current | Personal Fedora-based distro with niri + Noctalia v5 |

## Why msbos

**MSBOS** stands for **M**arcos **S**ouza **B**rito + **OS** (operating system). It is
the name of the personal distro; technically, it is still a suite of idempotent
scripts applied to an already installed Fedora, without its own ISO.

## Compatibility

If you installed a version called MyOS or omyfedora, the current installer migrates
paths, services and settings automatically. See
[Migration to msbos](migracao-msbos.en.md).
