# Histórico de nomes

O msbos já teve outros nomes. Eles aparecem apenas em releases antigas, nos
scripts de migração e nesta página — o restante da documentação usa o nome atual.

| Nome | Época | O que era |
|---|---|---|
| **MyOS** | início do projeto | Base GNOME; depois migrada para Fedora KDE |
| **omyfedora** | versão pública inicial | Fedora KDE + niri + Noctalia, instalado por scripts |
| **msbos** | atual | Distro pessoal baseada no Fedora, com niri + Noctalia v5 |

## Por que msbos

**MSBOS** vem de **M**arcos **S**ouza **B**rito + **OS** (sistema operacional). É o
nome da distro pessoal; tecnicamente, ela continua sendo uma suíte de scripts
idempotentes aplicada sobre um Fedora já instalado, sem ISO própria.

## Compatibilidade

Se você instalou uma versão chamada MyOS ou omyfedora, o instalador atual migra
os caminhos, serviços e configurações automaticamente. Veja
[Migração para o msbos](migracao-msbos.md).
