# omyfedora documentation

**omyfedora** is a personal customization of Fedora KDE with the **niri** compositor and the
**Noctalia v5** shell — it is neither a distribution nor an ISO. This folder holds the
documentation that does not fit in the [README](../README.en.md): detailed installation,
daily use, how the steps work, troubleshooting and credits.
