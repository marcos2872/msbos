# Documentação do omyfedora

O **omyfedora** é uma personalização pessoal do Fedora KDE com o compositor **niri** e o
shell **Noctalia v5** — não é uma distro nem uma ISO. Esta pasta reúne a documentação que
não cabe no [README](../README.md): instalação detalhada, uso diário, arquitetura das
etapas, solução de problemas e créditos.
