# Documentação do msbos

O **msbos** é minha distro pessoal baseada no Fedora, com o compositor **niri** e o shell
**Noctalia v5** — sem ISO própria. Esta pasta reúne a documentação que não cabe no
[README](../README.md): instalação detalhada, uso diário, arquitetura das etapas, solução de
problemas e créditos.
