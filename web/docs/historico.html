Histórico de nomes

As gerações anteriores do nome do projeto.

1 min de leituraVer no GitHub

O msbos já teve outros nomes. Eles aparecem apenas em releases antigas, nos scripts de migração e nesta página — o restante da documentação usa o nome atual.

NomeÉpocaO que era
MyOSinício do projetoBase GNOME; depois migrada para Fedora KDE
omyfedoraversão pública inicialFedora KDE + niri + Noctalia, instalado por scripts
msbosatualDistro pessoal baseada no Fedora, com niri + Noctalia v5

Por que msbos

MSBOS vem de Marcos Souza Brito + OS (sistema operacional). É o nome da distro pessoal; tecnicamente, ela continua sendo uma suíte de scripts idempotentes aplicada sobre um Fedora já instalado, sem ISO própria.

Compatibilidade

Se você instalou uma versão chamada MyOS ou omyfedora, o instalador atual migra os caminhos, serviços e configurações automaticamente. Veja Migração para o msbos.
