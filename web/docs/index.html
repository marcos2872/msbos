Documentação do msbos

Ponto de entrada de toda a documentação.

1 min de leituraVer no GitHub

O msbos é minha distro pessoal baseada no Fedora, com o compositor niri e o shell Noctalia v5 — sem ISO própria. Esta pasta reúne a documentação que não cabe no README: instalação detalhada, uso diário, arquitetura das etapas, solução de problemas e créditos.
