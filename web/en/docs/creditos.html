Credits

Fedora, KDE, niri, Noctalia, greetd and other upstreams.

2 min readView on GitHub

msbos is a personal Fedora-based distribution: it would not exist without the work of many people. This page records the main projects and communities that make this configuration possible. msbos is not affiliated with, endorsed by, or maintained by any of them.

Base and desktop

ProjectRole in msbosWhere
Fedora ProjectSystem base, packages, dnf, SELinux, systemd and release cyclehttps://fedoraproject.org
KDE CommunityKDE apps kept, Breeze Dark, plasma-integration, portals and polkit-kdehttps://kde.org
Fedora KDEReference image used as the recommended basehttps://fedoraproject.org/kde

Thanks to the Fedora Project and the KDE community for building and packaging the base on top of which msbos applies a personal layer.

Communities and maintainers

Thanks also to the translation, documentation, packaging and support communities of Fedora, KDE, niri, Noctalia and every project above. Bug reports, patches, documentation and discussions are what keep this ecosystem alive.

If you maintain one of these projects and find something in msbos that violates a convention or expectation, please open an issue in the msbos repository — the intent is always to respect and highlight upstream work.
