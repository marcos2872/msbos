Name history

The earlier generations of the project name.

1 min readView on GitHub

msbos had other names before. They appear only in old releases, migration scripts and this page — the rest of the documentation uses the current name.

NamePeriodWhat it was
MyOSproject startGNOME base; later migrated to Fedora KDE
omyfedorafirst public versionFedora KDE + niri + Noctalia, installed by scripts
msboscurrentPersonal Fedora-based distro with niri + Noctalia v5

Why msbos

MSBOS stands for Marcos Souza Brito + OS (operating system). It is the name of the personal distro; technically, it is still a suite of idempotent scripts applied to an already installed Fedora, without its own ISO.

Compatibility

If you installed a version called MyOS or omyfedora, the current installer migrates paths, services and settings automatically. See Migration to msbos.
