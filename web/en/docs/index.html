msbos documentation

Entry point for all documentation.

1 min readView on GitHub

msbos is my personal Fedora-based distribution, with the niri compositor and the Noctalia v5 shell — without its own ISO. This folder holds the documentation that does not fit in the README: detailed installation, daily use, how the steps work, troubleshooting and credits.
