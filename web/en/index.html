msbos

A lean, low-footprint desktop built on top of the Fedora you already have.

Route C, no custom ISO: an orchestrator of idempotent scripts swaps the Plasma shell for niri and Noctalia v5, installs the GPU driver and tunes memory and performance — while keeping the KDE apps.

What it is

The personal glue between excellent projects

msbos does not rewrite Fedora: it applies a personal layer on top of the existing base, kernel and apps. The result is a lean Wayland desktop with its own login, and your daily applications untouched.

No ISO

Route C

No build infrastructure: a bootstrap script downloads the repository and applies the configuration onto an already installed Fedora 44/45.

niri + Noctalia

Lean desktop

A Wayland compositor with scrollable tiling and a complete shell: bar, launcher, notifications, OSD, control center, lock screen and wallpaper.

KDE

Apps kept

Dolphin, Konsole, Kate/KWrite, Okular, Gwenview, Spectacle, Dragon, Elisa… stay installed and use Breeze Dark, KDE's default dark theme.

Layered

What sits on top of what

The swap happens at the session and shell layers. The system is still Fedora — the systemd, SELinux, dnf and kernel that were already there.

How it works

Seven base steps, one opt-in and two migration steps

install.sh discovers scripts/NN-*.sh in order and stops at the first failure. Every step detects before acting: re-running is safe.

10-gpu.sh

Detects the GPU — Intel/AMD/NVIDIA (including hybrid) and installs the driver; RPM Fusion and nvidia-drm.modeset=1 on NVIDIA.

20-stack.sh

Builds the stack — niri, Noctalia, greetd, audio, portals, apps; KDE app curation and schedules the Plasma shell removal.

25-devtools.sh

Tooling — gcc/make, GitHub CLI, Rust (rustup), Node LTS via nvm, pnpm/yarn and KVM/libvirt.

30-services.sh

Services and login — greetd takes over boot, other DMs masked, dispensable daemons disabled.

40-tuning.sh

Memory — zram zstd, sysctl, compress=zstd:1 on btrfs, oomd and power profile.

50-configs.sh

Configuration — niri, Noctalia, Breeze Dark, greetd/PAM, wallpapers, zsh, default apps and shortcuts.

60-agent-skill.sh

Privilege — polkit helper for AI agents, root lists and skills in ~/.agents/skills/.

55-niri-zoom.sh

Per-output zoom — Optional: builds the niri fork with per-monitor zoom into /usr/local/bin/niri.

Besides these, 00-migrate-names.sh prepares an old install and 99-cleanup-legacy.sh removes legacy artifacts once the new ones exist. On a fresh install both are no-ops.

Idempotent and backed up

Installation

From Fedora to the msbos login

Without cloning: the bootstrap downloads the .tar.gz, extracts it and runs install.sh. The shell swap takes effect on the next boot — nothing is stopped in the live session.

  • Recommended base: Fedora KDE (or a minimal install)
  • In a VM: virtio-gpu with 3D acceleration and GL on Spice
  • Requirements: Fedora 44/45 x86_64, internet and sudo
Installation guide
bash
curl -fsSL https://raw.githubusercontent.com/marcos2872/msbos/main/bootstrap.sh -o /tmp/msbos.sh
sudo bash /tmp/msbos.sh --dry-run   # simula tudo
sudo bash /tmp/msbos.sh             # instala
sudo reboot
